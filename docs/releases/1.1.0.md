# Moro 1.1.0 发布记录

- 版本与构建号：1.1.0 (40)，主 App、扩展及测试目标统一版本；正式包以 Xcode Cloud 分配的构建号为准。
- 10 种语言版本说明保存在 `metadata/app-store/version/1.1.0/`，其余资料沿用线上 1.0.9。
- 主要变化：
  - 全新首次启动：全屏起伏星网与闪电，一滑（或轻点）凝聚成可自由转动的星球，推进后进入登录页。
  - 登录页星图：已知服务器逐颗点亮、收窄并锁定，未收录的域名生成新星；输入框不再预填服务器。
  - 多账号切换、主题色与帖子字号、单页编辑个人资料、无头像/封面时的个性化占位。
  - 关注关系缓存与新帖提醒铃铛；保存与分享帖子图片、敏感内容设置。
  - 搜索发现分块加载，服务器关闭用户目录时改用推荐关注（如 m.cmx.im）。
  - 开屏控件的 VoiceOver 读取顺序与焦点范围修正；短图片说明不再留出多余空白。
- 本地回归（iPhone 17 Pro Max / iOS 26.2）：
  - 单元测试 594 项全部通过。
  - UI 测试 185 项：首轮 2 项失败（图片说明面板留白、个人主页顶栏测试步骤），修复后两组单独重跑通过；5 项按设计跳过。
- 商店素材：中英截图各 7 张（1320×2868）与预览视频各 1 支（886×1920，约 29.6 秒）位于 `build/qa/showcase/`；素材库横幅与搜索结果图位于 `build/qa/showcase/frame/out/assets/`。
