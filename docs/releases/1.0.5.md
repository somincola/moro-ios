# Moro 1.0.5 发布记录

- 对外版本：1.0.5。主 App、Share、Notification Service、Widgets 和测试目标的工程构建号统一为 27；正式安装包使用 Xcode Cloud 实际构建编号。
- 源码范围：跨站帖子链接打开、通知分页与刷新、私信内容和键盘修复、发帖与回复编辑器、提及和话题标签补全／高亮、搜索布局与底部导航。
- 正式构建：验证通过并合并到 `main` 后，手动运行 Xcode Cloud 的 `Moro - Release` 工作流。
- 商店设置沿用上一版的审核通过后自动发布方式。更新说明覆盖现有 10 种语言，完整文案保存在 `metadata/app-store/version/1.0.5/`。

## 简体中文更新说明

- 重新设计发帖与回复，支持 @ 和话题标签补全及高亮。
- 优化搜索与底部导航，让浏览和输入更自然。
- 改善私信与通知，修复链接显示、跨站帖子打开和键盘遮挡问题。

## English release notes

- Redesigned posting and replies with mention and hashtag suggestions and highlighting.
- Refined search and tab navigation for smoother browsing and typing.
- Improved messages and notifications; fixed link handling, opening remote posts, and keyboard overlap.
