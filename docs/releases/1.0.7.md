# Moro 1.0.7 发布存档

- 对外版本：1.0.7；主 App、扩展和测试目标的 12 个构建配置统一为 1.0.7 (33)。
- 发布分支：`main`，同步至 `dev`；源码标签：`v1.0.7`。
- 中文更新说明：**修复部分界面样式问题，优化图片浏览体验。**
- 10 种语言版本资料存于 `metadata/app-store/version/1.0.7/`，其余字段沿用已发布 1.0.6 的资料。

## 本次调整

- 图片预览在轻微拖动时保持视口稳定，首页头像与圆形背景居中。
- 时间线与详情的五个操作图标从 21pt 调整为 18pt，保留 44pt 点击高度、原操作逻辑和导航栏按钮尺寸。
- 时间线正文至工具栏的额外间距收至 2pt，移除工具栏下方的卡片外留白；无工具栏卡片沿用原底部间距。
- 详情主帖移除时间文案与工具栏之间的分隔线及工具栏底部外留白。

## 验证

- 2026-09-24，本地构建通过；iPhone 17 Pro / iOS 26.5 模拟器通过全部 549 项单元测试，以及浅色、深色、辅助功能大字号的 3 项详情页 UI 测试，共 552 项，零失败、零跳过。
- UI 测试将控件滚离底部系统手势区后检查边缘点击和展开行为；未修改产品交互逻辑。
- 工程 plist、版本一致性及元数据校验通过；App Store Connect 的 10 种语言资料已回读，六个字段均与本地存档一致。
- 审核联系方式、演示账号和审核备注与已发布 1.0.6 一致。App Privacy 已在 App Store Connect 确认发布。

## 发布记录

- 第 31、32 包不包含最终确认的全部工具栏调整，不用于本次送审。
- 最终包通过 `Moro - Release` 工作流从合并后的 `main` 构建，须核对源码与 `v1.0.7` 一致，云端测试、归档成功且包状态为 `VALID` 后提交 1.0.7 审核。
- 本地源码归档、测试结果、云端构建和送审回执保存在 `build/releases/1.0.7/`；审核账号凭据不写入源码存档。
- 1.0.6 保留现有已发布版本；1.0.7 配置为审核通过后发布。
