# Moro 1.0.4 发行记录

正式发行改用 Xcode Cloud。本机使用测试版 macOS，本地构建仅用于开发验证；此前生成的本地 IPA 和 Archive 不作为上传、送审或发行产物。

## 版本与范围

- 目标版本：1.0.4；Xcode Cloud 已分配并完成正式构建号 26。工程中的构建号 18 为本地验证编号，云端主 App、Share、Notification Service、Widgets 均为 1.0.4（26）。
- 2026-09-07，云端 1.0.4（26）已上传 App Store Connect 并处理为 `VALID`，随后完成多语言版本说明保存并提交审核，状态为 `WAITING_FOR_REVIEW`；商店当前公开版本仍为 1.0.3。
- 合并内容包含当前主线自 1.0.3 以来的搜索、资料编辑、书签、话题关注、离线缓存、正文解析与发布体验更新，以及本分支的回复预填充和讨论串阅读改进。

## App Store 版本说明

已按用户要求精简为每种语言 3 条，全部 10 种线上语言均已保存并回读核对：`ar-SA`、`de-DE`、`en-US`、`es-ES`、`fr-FR`、`it`、`ja`、`pt-PT`、`zh-Hans`、`zh-Hant`。

本次只更新 `whatsNew`。规范文件保存在 `metadata/app-store/version/1.0.4/`；其余本地化字段来自线上 1.0.3，保持原值。

### 简体中文

- 优化探索与搜索，支持最近搜索，返回时保留列表位置。
- 改善个人资料编辑，支持附加信息排序、精选标签和显示设置。
- 优化回复串阅读、@ 自动填充和通知，修复编辑帖子时的链接与标签问题。

### English

- Improved Explore and search, with recent searches and your list position preserved when you return.
- Refined profile editing, with reorderable extra fields, featured hashtags, and display settings.
- Improved reply threads, automatic mentions, and notifications. Fixed link and hashtag issues when editing posts.

## 验证与打包流程

1. 对 1.0.4 的代码运行 Debug 配置的 `Moro-AllTests`，记录通过、失败及需要登录环境而跳过的用例；演示数据和界面测试入口仅在 Debug 启用。
2. 检查 Release 构建、版本一致性、本地化和 Git 差异，完成后合并到 `main`。
3. 从已验证的 `main` 建立正式分支 `codex/release-1.0.4`，通过 Xcode Cloud 的 `Moro - Release` 工作流运行单元测试并生成 Release 归档。
4. 核对云端所用正式版 Xcode / macOS、提交、测试结果、归档及 App Store Connect 构建处理状态，以云端产物作为发行依据。

本记录保存 1.0.4 的验证、云端打包与送审结果；公开发行状态以 App Store Connect 为准。
