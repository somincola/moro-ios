# Moro 1.0.4 发行准备

## 版本与范围

- 目标版本：1.0.4，构建号：18；主 App、Share、Notification Service、Widgets 的 Debug / Release 配置一致。
- 2026-09-07 核对 App Store Connect：1.0.3 已发行，已处理及正在上传的最高构建号均为 17，建议下一构建号为 18。
- 合并内容包含当前主线自 1.0.3 以来的搜索、资料编辑、书签、话题关注、离线缓存、正文解析与发布体验更新，以及本分支的回复预填充和讨论串阅读改进。

## 发行说明草稿

### 简体中文

- 探索与搜索更清晰，支持最近搜索，并在返回时保留原来的列表位置。
- 重新整理个人资料编辑，支持编辑、删除和拖动排序附加信息，以及精选话题标签和资料显示设置。
- 优化帖子详情阅读：保持完整阅读宽度，用清晰的讨论边界区分回复，长回复串可以整串收起。
- 回复时一次填入合适的提及账号，改善编辑预览、媒体排序和通知显示。
- 改善书签筛选、离线阅读、列表缓存和话题关注体验。
- 修复编辑帖子时链接丢失、标签清理误删及部分富文本显示问题。

### English

- Explore and search are clearer, with recent searches and your list position preserved when you return.
- Profile editing now supports editing, deleting, and reordering extra fields, plus featured hashtags and profile display settings.
- Post details keep the full reading width, with clearer discussion boundaries and one control to collapse an entire long reply thread.
- Replies fill in the relevant mentions together. Post previews, media ordering, and notifications have also been improved.
- Improved bookmark filters, offline reading, list caching, and followed hashtags.
- Fixed links disappearing when editing posts, incorrect hashtag cleanup, and several rich text rendering issues.

## 验证与打包流程

1. 对 1.0.4 的代码运行 Debug 配置的 `Moro-AllTests`，记录通过、失败及需要登录环境而跳过的用例；演示数据和界面测试入口仅在 Debug 启用。
2. 检查 Release 构建、版本一致性、本地化和 Git 差异，完成后合并到 `main`。
3. 从已验证的 `main` 使用 Xcode 26.6 的 `xcodebuild archive` 生成 Release 归档，再导出 App Store Connect 用 IPA。
4. 检查归档 / IPA 中主 App 与所有扩展的版本号、构建号、签名和应用标识，保留结果包与校验值。

本记录用于本地发行准备；商店送审与公开发行状态以 App Store Connect 的实际操作为准。
