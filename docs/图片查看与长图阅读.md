# 图片查看与长图阅读

## 交互

- 没有 ALT 或 ALT 只有空白字符时，不显示描述按钮或底栏。
- 有 ALT 时，顶部工具栏提供 44 pt 的 ALT 按钮。点击打开可滚动、可选择复制的描述面板，关闭后保持当前图片的缩放与滚动位置。
- 描述面板只保留一处标题，关闭按钮的布局点击区域为 48 × 48 pt，在系统浮动面板缩放后仍不小于 44 pt。短描述按正文实际高度收紧；长描述初始高度最多约为查看区域的 60%，可向上展开并滚动阅读。也可下拉关闭。
- 面板高度根据实际排版测量，跟随窗口宽度、系统字号和应用字号变化；标题与关闭按钮固定在正文滚动区域外。
- 单击图片切换工具栏；双击、捏合或拖动图片时收起工具栏。隐藏的控件从视图与无障碍树移除，避免透明按钮挡住图片。
- VoiceOver、切换控制运行时保留工具栏。图片本身提供描述和缩放自定义动作，支持无障碍退出手势。
- 初始展示完整图片；长图双击放大到适合屏幕宽度，并以点击位置作为阅读中心。普通图片双击放大，再次双击回到全图。
- 全图状态下可左右翻页、向下拖动关闭；放大后拖动用于阅读图片，图片到达边缘也不会误翻页或关闭。
- 本轮不增加全局设置开关，不改变发帖时的 ALT 提醒设置。

## 实现

`ImagePreviewView` 管理分页、工具栏与描述面板；`ImagePreviewScrollView` 使用系统 `UIScrollView` / `UIImageView` 执行缩放、惯性滚动、边界回弹和点击定位。捏合与平移逐帧变化留在 UIKit，不回写 SwiftUI 的页面状态。

放大期间暂停外层分页滚动，恢复全图、离开窗口或销毁查看器时恢复分页。工具栏显隐与 ALT 展开不重新加载图片。屏幕尺寸变化时保留阅读中心，并重新计算有效滚动范围。

继续使用 SDWebImage 的下载与缓存。查看器专用解码器从图片文件头读取实际尺寸，再按最多约 8 Mi 像素（普通 RGBA 位图约 32 MiB）、最长边 16384 像素进行解码；多帧图片按帧数分摊像素预算。该预算仅指解码像素，不是整个查看器或进程的内存上限。

项目锁定的 SDWebImage 5.21.6 静态 ImageIO 解码路径未采用 `imageScaleDownLimitBytes`，因此不单独依赖该参数；通过显式缩略图尺寸在解码前限制像素。缩略图缓存键与时间线显示资源区分，避免放大时复用低清缩略图。切换 URL 或销毁页面会取消未完成请求，旧请求回调不能覆盖新图片。

## 验证入口

- `moroTests/ImagePreviewTests`：描述空值、全图适配、长图按宽放大、点击定位、阅读位置保持、旋转与滚动边界，以及真实图片解码的清晰度和像素预算。
- `moroUITests/ImagePreviewUITests`：真实查看器中的工具栏显隐、ALT 面板、长图底部、缩放后的拖动、分页、下拉关闭与捏合缩放。ALT 用例覆盖短文、中等长度正文、长文展开、关闭后重新打开、深色外观和辅助功能大字号。
- Debug 启动参数 `UITEST_IMAGE_PREVIEW` 打开本地图片测试页；环境变量 `UITEST_IMAGE_INDEX` 可选择第 0、1、2 张，`UITEST_ALT_TEXT` 可替换第 1 张的描述。使用本地生成并写入缓存的长图与横图，不需要登录或访问网络；测试保留系统动画。
- 模拟器回归验证交互正确性，不能据此报告真机帧率或卡顿下降比例。
