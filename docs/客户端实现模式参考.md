# 客户端实现模式参考

本文整理 Mastodon 客户端在各功能上常见的实现方式和取舍，供设计或调整 Moro 相关能力时作为备选思路。只描述模式，不对应任何具体项目的代码结构；Moro 的现行约束以各契约文档为准，两者冲突时以契约文档和生产代码为准。

## 1. 导航与路由

- **中心协调器**：由一个协调器统一创建页面并决定展示方式（push、modal、分栏详情替换），可导航的场景和转场方式都用枚举显式列出。导航逻辑集中、编译期可检查、便于在测试中替换；代价是协调器容易膨胀，需要按功能拆分子协调器。
- **视图不直接持有下一个页面**：ViewModel 通过一个"动作处理"协议把导航请求交给协调器，页面之间不互相依赖。
- **按上下文选择展示方式**：处于导航栈中时 push，处于分栏布局时替换详情区，其余情况 present。
- **每个 Tab 独立导航栈**：切换 Tab 保留各自位置；跨 Tab 跳转先切 Tab 再压栈。
- **返回交给系统**：使用系统返回按钮和边缘手势；连续进入同类页面（如主页 → 主页）时自定义返回标题，标题过长时只显示箭头。
- **返回后的数据回写**：详情页里的互动通过全局更新中心广播，列表页订阅后就地合并，而不是返回时重新拉取。
- **iPad 分栏**：记录二级页面栈，用来判断新页面是替换详情区还是继续追加。

Moro 现行方案见 [界面与导航契约](界面与导航契约.md)。

## 2. 登录与实例接入

- **域名规范化**：去除首尾空白、转小写、缺少协议时补 `https://`、只取 host，并要求至少包含两段（如 `example.com`）。
- **实例校验**：优先请求 `/api/v2/instance`，失败回退 `/api/v1/instance`；可选用 WebFinger 预先确认是 Mastodon 实例。
- **OAuth 授权码流程**：先 `POST /api/v1/apps` 注册应用取得 client 凭证，再用系统认证会话（临时浏览器会话）打开授权页，通过回调 scheme 拿到 code，`POST /oauth/token` 换取 token，最后用 `verify_credentials` 确认账号再落库。
- **凭证存储**：放在 Keychain，按账号隔离；用户主动取消授权时静默处理，不弹错误。
- **注册流程**：用 `client_credentials` 取得应用级 token → 展示实例规则与隐私政策 → `POST /api/v1/accounts`（用户名、邮箱、密码、同意规则、语言，可选注册理由和出生日期）→ 按实例要求进入邮箱确认。
- **语言回退**：设备语言不被实例支持时，改用实例支持的语言或默认语言。

Moro 现行方案见 [认证与 URL 回调](认证与URL回调.md)。

## 3. 时间线加载与缓存

- **缓存优先**：启动时先显示本地缓存，同时后台拉取最新内容，新数据到达后平滑合并。
- **双向分页**：下拉刷新用 `since_id` / `min_id` 取更新内容，上拉加载用 `max_id` 取更早内容；分页参数从响应头 `Link` 的 `next` / `prev` 解析。
- **实时更新**：通过 streaming 长连接接收新帖、编辑、删除和通知事件；进入后台断开、回到前台重连，网络切换时重建；不可用时降级为轮询，并按网络状况调整频率。
- **多级缓存**：内存缓存放最近访问的数据；本地数据库按账号存时间线和用户信息，用于恢复浏览位置；媒体文件用哈希命名缓存到磁盘，定期清理。

## 4. 帖子模型与正文渲染

- **统一帖子模型**：把时间线、通知、引用中的 status 归一成一套模型。正文拆为"HTML + mentions/tags/emojis 元数据"、内容警示、附件（媒体、投票、链接卡片三类）、计数和"我的互动状态"。类型区分普通帖、转帖、引用帖：转帖外层显示转发者，内容取内层帖子；引用帖有完整内容时内嵌显示，只有 ID 时显示占位并允许点进详情。
- **预处理**：去掉正文中内联的引用段落（`quote-inline`），避免引用正文渲染两次。
- **HTML 渲染管线**：HTML → 块（段落、列表、引用块）→ 行（嵌套格式、缩进、编号或圆点前缀、引用彩条）→ 行内元素拼接为可换行的文本；`invisible` 片段隐藏，`ellipsis` 片段截断显示。链接统一使用系统链接色。
- **自定义表情**：按冒号切分文本，命中 shortcode 的片段先插入占位，批量下载表情图并按当前字号缩放，下载完成后替换占位并对齐基线；下载失败时退回 `:shortcode:` 文本，不影响排版。
- **纯文本导出**：分享、复制和 VoiceOver 复用同一个解析器，把块和行重新拼成字符串。
- **翻译**：原文和译文 HTML 之间切换，投票选项和图片 ALT 一并切换，底部提供"显示原文"。

Moro 现行方案见 [帖子组件与交互契约](帖子组件与交互契约.md)。

## 5. 链接、话题与提及

- **统一拦截**：在帖子视图层拦截链接打开动作，按以下顺序识别：
  1. 提及：链接 URL 与 `mentions[].url` 完全匹配 → 打开用户主页。
  2. 话题：路径包含 `tags`，且最后一段与 `tags[].name` 不区分大小写匹配 → 打开话题时间线。
  3. 站内帖子链接 → 打开帖子线程。
  4. 其他外链 → 应用内浏览器打开，非 ASCII 字符先做百分号编码。
- **以实体数据为准**：HTML 负责显示，实体数据负责跳转目标；两者对不上时按普通外链处理。
- **跨实例提及**：先按账号 ID 拉取完整账号信息，再进入主页。
- **话题格式校验**：支持 Unicode 字母、数字、下划线、中间点和零宽非连接符，至少包含一个字母。
- **测试要点**：大小写差异、特殊字符、跨实例话题和提及、未登录状态。

## 6. 媒体展示

- **宫格布局**：单图按原始比例全宽；2–3 张单行排列并按宽高比分配宽度；4 张及以上分两行（上行 ⌈n/2⌉，下行 ⌊n/2⌋），图片间距 1pt。
- **Blurhash 占位**：按小尺寸（最长边约 20pt）异步生成并缓存，真实图片加载完成后覆盖在占位图上。
- **全屏预览**：记录被点击图片在屏幕上的位置，从缩略图平滑过渡到全屏，支持左右滑动切换。
- **ALT 文本**：有 ALT 时在图片角落显示标记，点击弹出完整文本，可随翻译切换。
- **动图、视频与音频**：GIFV 当作视频循环播放；视频未播放前用 blurhash 作封面，点击后播放或进入全屏；音频提供播放暂停、进度条、时长和前后跳转 5 秒。

Moro 现行方案见 [图片查看与长图阅读](图片查看与长图阅读.md)。

## 7. 内容警示与过滤

- **两层遮罩**：外层是服务器过滤规则命中，内层是内容警示（CW），用户逐层展开。
- **三种显示模式**：不遮罩；遮罩全文（附原因，正文和媒体同时展开）；仅遮罩媒体（正文可见，媒体角落提供显示 / 隐藏）。
- **遮罩时不加载原图**：媒体只显示 blurhash，播放器不创建，并把媒体区高度限制在约 100pt。
- **嵌套内容**：引用帖有独立的遮罩状态；父帖重新隐藏时递归隐藏所有嵌套内容。

## 8. 对话线程

- **数据**：`GET /api/v1/statuses/{id}/context` 返回 ancestors 和 descendants，与焦点帖拼成"祖先 → 焦点 → 后续回复"。
- **祖先链**：沿 `in_reply_to_id` 逐级向上查找，自然覆盖同一用户连续回复自己的情况。
- **位置标记**：给每条帖子标记它在线程中的位置（根、焦点、分支开始、分支延续、分支结束），据此绘制头像上下的连接线；连续与不连续的连接线样式不同。
- **定位**：打开详情后自动滚动到焦点帖，且只滚动一次。

## 9. 互动：转发、点赞、收藏

- **统一流程**：界面触发 → 处理层 → API → 返回最新 status → 全局更新中心广播 → 各列表就地合并。
- **乐观更新**：先更新界面，失败时回滚并提示；操作进行中标记"处理中"，防止重复点击。
- **转发**：实例支持引用时，先让用户选择"转发"或"引用"；转发可指定可见性；接口返回的结果需取内层被转发的帖子。
- **收藏**：只有状态，没有计数。
- **引用按钮状态**：取决于用户默认可见性（仅提及可见时不可引用）和原帖的引用审批状态。

## 10. 发帖

- **上下文与目标**：上下文分为新帖（可附带引用）和编辑（需原始 source 文本）；目标分为顶层帖和回复。
- **回复预处理**：自动 @ 原作者和原帖中提及的用户（排除自己并去重），继承内容警示，可见性不比原帖更宽松。
- **引用策略**：任何人、仅关注者、不允许；仅关注者可见和仅提及可见的帖子只能设为不允许。
- **发布流程**：生成幂等键 → 逐个上传媒体并写入 ALT → 收集媒体 ID → 整理投票选项与过期时间 → 提交；进度按各步骤权重计算；发布任务进入队列，失败时保留草稿以便重试。
- **发布前检查**：提醒缺少 ALT 的媒体（可选）；拦截"非公开帖引用他人帖子"的冲突。
- **字数计算**：URL 按固定长度计入。
- **自定义表情**：按实例缓存表情列表，加载失败后定时重试；建立 shortcode 字典和前缀树，用于输入时自动补全。
- **编辑模式**：恢复原有附件、内容警示和未过期的投票；可见性锁定，引用策略可以修改。

Moro 现行方案见 [发帖可靠性与正文首屏显示](发帖可靠性与正文首屏显示.md)。

## 11. 通知与多账号

- **通知统一入口**：推送、streaming 和轮询多个来源去重合并；支持按类型筛选和未读角标；点击时按通知类型路由到帖子或主页，并处理从通知冷启动应用的跳转。
- **多账号**：账号以"实例域名 + 用户 ID"唯一标识；凭证、偏好设置和缓存按账号隔离；推送按账号路由；切换账号时保留各自的浏览位置。

Moro 现行方案见 [Push 通知与订阅契约](Push通知与订阅契约.md)。

## 12. 错误处理

- **分类**：网络错误、HTTP 错误（4xx / 5xx）、业务错误（校验失败、权限不足、资源不存在）。
- **策略**：网络错误用指数退避自动重试有限次，同时提供手动重试；认证失效引导重新登录；用户主动取消的操作静默处理；其余错误给出可理解的提示并记录日志。

Moro 现行方案见 [API 验证指南](API验证指南.md)。
