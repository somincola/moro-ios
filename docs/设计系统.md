# Moro 设计系统

本文定义当前视觉实现的长期约束。具体数值以主题源码为准；页面不得复制颜色、字号或间距常量形成第二套设计系统。

## 设计原则

- 阅读优先：正文、身份和状态变化先于装饰。
- 单色品牌：当前 `MoroAccentStyle` 只使用 `monochrome`，选中态依靠语义色、字重和形态表达。
- 语义优先：页面选择“正文色”“页面背景”“浮层表面”等角色，而不是直接写十六进制颜色。
- 原生行为：Dynamic Type、深色模式、VoiceOver、Reduce Motion 和系统触控习惯是默认能力。
- 克制分层：信息流使用全宽 row；只有输入、摘要、错误和明确分组才使用卡片表面。

## 色彩语义

统一从 `MoroTheme.colors` 读取：

| 角色 | Token |
|---|---|
| 主操作、选中态 | `primary500` / `primary600` |
| 主、次、弱文字 | `textPrimary` / `textSecondary` / `textTertiary` |
| 分组页面背景 | `groupedBackground` |
| 基础、弱化、抬升表面 | `surfaceBase` / `surfaceSubtle` / `surfaceElevated` |
| 分隔线与弱边框 | `divider` / `borderSubtle` |
| 链接 | `contentLink` |
| 成功、警告、错误 | `success` / `warning` / `error` |
| 主色上的前景 | `primaryForeground` |
| 沉浸式媒体背景 | `immersiveBackground` |

浅色与深色由 token 自行切换。功能页面不得写死 `.white`、`.black` 或固定灰色来表达常规文字和表面；纯黑只用于明确的沉浸式媒体语义。

## 字体

- 使用 `MoroTypography` 的语义字体：title、subtitle、body、bodyStrong、caption。
- 默认视觉基准分别对应 20、17、15、15、13pt，但仍由系统 text style 响应 Dynamic Type。
- 应用内字号缩放叠加在 Dynamic Type 上，不能用固定高度抵消文字增长。
- 用户内容不得为了保持单行而缩小字号；身份行等紧凑区域优先定义明确的截断优先级。

## 间距与尺寸

`MoroSpacing` 的基础尺度为 2、4、6、8、10、12、16、20、24、32pt。时间线使用专用 token 管理 row 垂直间距、头像与正文间距、操作区间距和分隔线缩进。

- 页面内优先组合已有尺度，不新增只服务单个页面的近似值。
- 图标的视觉尺寸与触控尺寸分开：视觉大小按上下文确定，点击区域至少 44×44pt。
- 圆角、阴影和边框必须服务于层级或可操作性，不能仅为“卡片化”重复添加。

## 图标

- 图标库是实现细节；产品语义、辅助功能标签和布局不得依赖资源文件名。
- 同一操作在导航栏、菜单和帖子工具栏中保持含义一致；选中态可通过 fill/weight 表达。
- 自定义或第三方图标必须使用模板渲染以继承语义前景色，危险操作使用与文字相同的 destructive 色。
- 无文字工具栏必须为每个按钮提供准确的 `accessibilityLabel` 和状态说明。

## 辅助功能与验收

- 覆盖浅色、深色、默认字号和 Accessibility XXXL。
- 不能只用颜色区分选中、错误或订阅状态。
- 文字、图标、焦点环和禁用态保持足够对比度。
- Reduce Transparency 或 Increase Contrast 下，不应丢失主要信息层级。
