# 帖子组件与交互契约

本文记录 Moro 自身的帖子结构、数据一致性和交互边界。

## 组件结构

```text
TimelinePostRow
└── PostCard
    ├── PostHeader / PostAuthorInfo
    ├── PostContent
    │   ├── RichTextContentView
    │   ├── ContentConcealView
    │   ├── MediaGrid / Video / Audio
    │   ├── PollView
    │   ├── Quote preview
    │   └── PostTranslationSection
    ├── PostFooter
    └── PostToolbar

StatusDetailView
├── DetailPostCard
└── ThreadPostRow
```

- 时间线与详情复用正文、媒体、投票、富文本和互动服务，但可以使用不同的信息密度。
- 时间线 row 不应为详情页重新实现一套业务逻辑；详情页只增加线程上下文和焦点帖层级。
- 测试 Harness 或 Preview 必须复用生产组件，不能复制一份测试专用帖子 UI。

## 身份与转发语义

- `Status.id` 表示当前列表实体；`displayStatus` 表示真正被展示和互动的 canonical 帖子。
- 转发包装保留外层转发者语义，正文、媒体、投票和互动状态来自 canonical 帖子。
- Feed 更新需要同时匹配外层 ID、canonical ID 和其他引用同一 canonical 帖子的转发包装。
- 作者身份区保持两行稳定结构：首行昵称与时间，次行账号；长昵称优先截断，时间不得掉入账号行。
- 自定义表情使用静态资源渐进替换，不能阻塞昵称文字首屏显示。

## 正文与链接

- Mastodon HTML 统一经 `ContentParser` 和 `RichTextContentView` 转为可显示片段。
- `ContentDOMParser` 使用固定版本 SwiftSoup 按 DOM 顺序提取正文；实体只解码一次，保留行内节点之间的空格、完整链接目标与代码缩进。不要再通过正则替换 HTML 或向正文注入占位符。
- 标签只在末尾整行均为 API 已知标签链接时交给标签条展示；正文中的标签、同名普通链接、代码和含图片的行必须保留。
- mention、hashtag、账号资料链接和普通 URL 由统一 URL 处理链识别，再映射到 `Route` 或外部浏览器。
- 服务器正文、翻译正文和复制用纯文本必须保持来源明确，不能用 UI 截断结果作为复制内容。
- 行内 code 与块级 code 保留各自排版语义；代码块不得破坏帖子整体横向布局。
- Content Warning、过滤器和敏感媒体是不同状态：正文揭示、媒体揭示和服务器过滤提示不得互相覆盖状态。

## 媒体、投票与引用

- 1～4 张图片使用同一媒体入口；单图根据元数据约束比例，多图使用稳定网格。
- 视频/GIF/音频拥有独立播放生命周期，离屏后停止不必要工作。
- ALT 是附件级数据，编辑、删除和重试必须按附件稳定 ID 操作，不能依赖可变化的数组 index。
- 删除上传中的附件后，迟到的上传结果不得把附件重新插回页面。
- 投票选项、已投状态、截止状态和服务端更新应由 Poll 模型驱动；投票与媒体的 Compose 互斥规则不得在展示层重复定义。
- Quote 与 Reblog 是不同语义：Quote 显示嵌入内容并可导航，Reblog 显示转发上下文并复用 canonical 状态。

## 互动状态

- `PostInteractionService` 负责喜欢、转发、书签等请求与本地乐观状态。
- `FeedCoordinator` 将成功结果、失败回滚、删除和新帖事件广播给时间线、详情、Profile 与 Hashtag 等消费者。
- 服务端返回旧计数时，本地必须保持本次已确认操作的计数单调性，随后再由权威刷新校准。
- `private` / `direct` 等不可转发帖子必须明确禁用操作，不能只依赖服务端报错。
- 危险操作保留确认或清晰的破坏性角色；更多菜单只组织入口，不复制操作实现。

## 布局与辅助功能

- 主时间线保持全宽 row 与分隔线，不额外包一层通用卡片。
- 头像、正文、媒体和工具栏在 Dynamic Type 下允许纵向增长；不通过隐藏信息解决溢出。
- 工具栏触控区域至少 44pt，图标与计数必须有组合后的可访问性语义。
- 媒体必须暴露 ALT；敏感内容揭示按钮说明当前状态和执行结果。
- Reduce Motion 下，互动反馈保留状态变化但应弱化位移、粒子和弹跳。

## 回归基线

至少覆盖：

- 短文、长文、mention/hashtag/URL、emoji、行内与块级 code。
- Content Warning、服务器过滤、敏感与非敏感媒体。
- 单图、2～4 图、视频、音频、投票、Quote、Reblog。
- 默认字号、Accessibility XXXL、浅色、深色和窄屏。
- 乐观成功、失败回滚、缓存重校准、删除与迟到响应。

## 外部参考规则

- 需要比较官方客户端时，应记录上游仓库 URL、commit 和结论，不复制数千行源码解析到本仓库。
- 外部实现用于发现协议边界和交互思路，不用于判断 Moro 当前是否缺少功能。
- 能转化为 Moro 长期约束的结论写入本文；只对某个上游版本有效的文件路径和代码摘录留在研究过程或 Git 历史中。
