## 缓存边界

| 显示项 | 清理范围 |
| --- | --- |
| 图片与媒体 | `ImageCache` 下载文件、SDWebImage 下载文件及解码内存缓存 |
| 时间轴内容 | `TimelineCache` 的 `.cache` 内容副本与对应内存 |
| 网络缓存 | `URLCache.shared` 的响应缓存 |

保留 Keychain 登录信息、多账号、偏好设置、草稿及分享附件、书签和阅读记录。尤其保留时间轴 `.meta` 中的 last-seen 标记，不执行退出登录的整库清理流程。

Moro 图片磁盘缓存上限 128 MiB，SDWebImage 上限 256 MiB，图片有效期 7 天。Moro 在写入时限额，SDWebImage 使用库提供的过期清理机制。所有大小以实际文件统计为依据，完成删除后重新统计；下载会在后续浏览中重新产生缓存。

Moro 图片磁盘操作在串行 utility 队列执行，清理轮次令清理前开始的下载失去写回资格。读取轮次只使用短锁，不阻塞等待磁盘扫描。时间轴读写共享 actor，清理内容时先移除待写内容，再保留并落盘阅读元数据。
