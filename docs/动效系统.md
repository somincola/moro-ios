# Moro 动效系统

动效用于解释状态变化和确认操作，不作为独立装饰层。交互状态机和数据结果优先于动画是否播放。

## Token

| 类别 | 当前值 |
|---|---|
| duration | `xs 0.10s`、`sm 0.16s`、`md 0.22s`、`lg 0.28s`、`xl 0.50s`、`xxl 0.60s` |
| translation | `xs 2pt`、`sm 4pt`、`md 8pt`、`lg 12pt` |
| scale | 按压 `0.94`、轻弹 `1.06`、强调弹跳 `1.12` |
| opacity | 列表起始 `0`、Modal 背景 `0.38` |

曲线统一使用 `AnimationTokens.easing` 中的 easeOut、easeInOut 和 soft/medium/firm spring，不在页面内创建含义重复的时长与弹簧参数。

## 使用边界

- 按钮按压：使用现有交互组件或 `.moroTapFeedback()`，但不得用额外 tap gesture 吞掉 Button 的原生行为。
- 喜欢、转发等状态确认：使用 `.moroBounce(trigger:)` 或 `PostActionEffectHost`；失败回滚同样必须清晰可见。
- 内容插入与切换：使用 `.moroSlideFade` 或 `.moroStandard`，避免对长列表中所有 cell 同时播放入场。
- Sheet 和局部浮层：由系统转场优先；只有自绘浮层才使用 `.moroModalTransition`。
- 加载：锁定反馈位置，避免文案或 spinner 导致按钮宽度跳动。

## 交互状态

手势与异步操作至少区分：

```text
idle -> preparing -> ready -> committed/loading -> finished -> reset
                   \-> cancelled -> reset
```

- 未达到阈值必须无副作用取消。
- 达到提交点后立即给出可见反馈；请求完成前禁止重复提交。
- 网络结果决定最终状态，动画结束不能被当作业务成功。
- 页面消失、任务取消或状态被外部刷新时，应终止不再可见的延迟动画。

## Reduce Motion

检测 `accessibilityReduceMotion`。开启后保留颜色、图标、计数和进度等状态反馈，弱化或移除位移、缩放、弹跳和粒子效果；不得因此跳过请求、确认或失败回滚。
