# Moro 回归测试矩阵

本文是当前产品结构的手工与自动化验证入口，不记录某次发布的执行结果。测试结果应附在对应 commit、PR 或 Release，而不是回写成长期历史日志。

## 验证层级

| 层级 | 目的 |
|---|---|
| Unit / model | 编解码、状态归一、缓存、去重、失败回滚和路由解析 |
| Harness / snapshot | 可重复的组件布局、主题和辅助功能基线 |
| Simulator | 导航栈、键盘、Sheet、安全区、系统 Tab Bar 和深链 |
| 真机 | Push、Share、Widget、相册/相机、视频、触感和性能 |

## 核心矩阵

| 区域 | 必测场景 |
|---|---|
| Auth | 实例校验、取消 OAuth、state 不匹配、token 交换失败、会话恢复、多账号切换/移除 |

| List offline cache | 不同账号/列表/内置来源隔离、重命名、冷启动读盘、首屏分批渲染不截断缓存、切换后继续填充、网络失败保留及重试、冷缓存修改/去重、待显示内容的编辑与删除、损坏/过期缓存、标记恢复、写入失败重试、内存释放与账号磁盘清理 |
| Post | 长短正文、CW、过滤、emoji、mention/hashtag/URL、code、媒体、投票、Quote/Reblog |

| Interaction | 喜欢、转发、书签、回复、删除、置顶、举报；成功、失败回滚和跨页面同步 |
| Compose | 新帖、回复、引用、编辑、可见性、引用策略、语言、CW、投票、媒体上传/重试/ALT |

| Thread reading | 分支折叠与展开、作者筛选保留前文、父帖与当前帖定位、重复/孤立/循环回复及 2,000 层回复排序 |
| Followed topics | 标题关注状态、失败重试、重复点击、Link 关系游标、末页、分页去重、取消关注失败保留行、返回刷新和账号隔离 |

## 视觉与辅助功能

高频页面至少覆盖浅色、深色、默认字号和 Accessibility XXXL：

- Timeline、帖子详情、Profile、Compose、Search、Inbox、Settings。
- 触控区域至少 44pt，图标按钮有语义标签，焦点顺序符合阅读顺序。
- 长文案、长昵称、本地化文本和系统 Bold Text 下不依赖裁切维持布局。
- Reduce Motion 下仍能理解提交、完成、失败和选中状态。

## 性能观察

- 启动到首个可用页面、时间线首屏和来源切换。
- 长列表滚动、图片解码、视频离屏停止和关系缓存命中。
- Compose 首次键盘、相册选择、附件预处理、草稿载入和后台保存。
- 只根据 Instruments、MetricKit、Organizer 或可重复测量创建优化任务，不根据单次体感改写架构。

## 命令

```sh
set -o pipefail && xcodebuild -project moro.xcodeproj -scheme moro -sdk iphonesimulator -configuration Debug build 2>&1 | rg -n "error:|BUILD (SUCCEEDED|FAILED)"

set -o pipefail && xcodebuild -project moro.xcodeproj -scheme moro -destination 'platform=iOS Simulator,id=460D37C1-EE1F-440D-9F0C-BAB4A85EC694' -configuration Debug test -only-testing:moroTests 2>&1 | rg -n "\\*\\* TEST|error:|fail|passed|Executed"
```

UI 或系统集成改动不能只以单元测试代替真实页面/真机复核；文档改动本身只需执行链接、路径和 Markdown 差异检查。
