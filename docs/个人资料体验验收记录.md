# 个人资料体验验收记录

日期：2026-09-06。开发分支：`codex/profile-experience`，基于 `main` 的 `aedf287`。

## 交付范围

- 编辑帖、投票结束通知使用帖子作者头像和统一事件角标，点击仍指向对应帖子或作者。
- 编辑资料拆为基本资料、附加信息、精选标签、资料显示四个入口。附加信息支持单项草稿编辑和拖动排序；保存时提交完整数组，保留原始链接与未修改字段，并检查远端冲突。
- 精选标签支持建议、添加、删除与个人主页单选筛选；普通帖和置顶帖共享筛选条件，详情返回保留选择。
- 标签栏的显示条件为 **Moro 开关开启，并且所浏览主页有精选标签**。开关按当前登录账号本地保存，控制该账号在 Moro 中浏览主页的体验；与服务器网页推荐账号页的 `show_featured` 独立。
- 服务器支持时提供媒体页、媒体回复、关注列表公开及网页精选页设置；旧实例禁用不支持的选项，保留可用设置。
- 新增 28 条文案，覆盖德、英、西、法、意、日、葡萄牙葡语、简体中文、繁体中文共 9 种语言。

重点覆盖了原始简介链接、字段顺序保存后回显、子页面放弃草稿、标签增删成功与失败、开关与空列表的显示条件、筛选详情返回、旧请求与实时事件隔离，以及旧实例兼容。连续三个无回复页面后转为手动加载，避免大账号无限自动请求。

真实账号仅用于读取资料与布局验证；修改资料、排序、标签增删和服务器设置使用 DEBUG 专用隔离 HTTP 测试环境，没有向真实账号提交测试修改。

## 附加信息交互补充验收（2026-09-06）

附加信息列表改为默认编辑、按需排序：默认整行可点击并显示编辑箭头，左滑可删除；排序状态显示原生删除控件和拖动手柄，完成排序后恢复编辑入口。单项编辑页保留删除按钮，所有操作只修改草稿，显式保存后提交完整字段数组。

- 4 项相关 UI 测试通过：排序后编辑并保留原始链接、点击行内空白区域编辑并放弃删除草稿、左滑删除保存后回显且保留其他字段、放弃单项编辑草稿。结果包：`/tmp/moro-profile-fields-actions-verified.xcresult`。
- 模拟器构建通过；手动检查英文浅色默认字号、中文深色默认字号、德语深色 Accessibility XXXL 下的普通与排序布局、长按钮文案换行，以及排序状态的单项删除。
- 最后统一了列表计数与操作的字号，将排序按钮的 44pt 点击区域放入按钮标签内，并再次构建、手动验证排序切换与整行编辑。
- 新增 3 条操作说明与按钮文案，9 种语言完整；测试修改均使用隔离 HTTP 环境，未修改真实账号资料。
